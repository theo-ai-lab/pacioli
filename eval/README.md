# Eval

The deterministic engine is treated as what it is — a classifier — and scored per class.

## The two numbers (kept apart by the provenance firewall)

1. **Detector accuracy** — does the engine reproduce the human labels? Measured on the synthetic
   fixtures + (separately) the documented incidents. Reproducible; not a claim about the real world.
2. **Agent-misbehavior rate** — of *real* runs you commissioned (`self-run` / `gmail` provenance),
   how many misbehaved? The only "real" headline number; needs live-card captures, never faked.

## Reproduce

```bash
# 1) unit tests for the engine (TDD)
npm test

# 2) per-class precision/recall in the terminal, from the labeled set
npm run eval

# 3) the citable harness — Inspect AI, frozen seed-shuffled held-out split, with standard error.
#    The TypeScript engine is the single classifier; this only scores its predictions.
npm run eval:build        # engine -> eval/dataset.jsonl  (id, text, gold[], predicted[])
inspect eval eval/discrepancy_eval.py --model mockllm/model -T split=all -T seed=1234
```

The engine is deterministic (no learned parameters), so the seed-shuffled split (`-T split=test`) is for
reproducible partitioning, not overfitting control; the headline runs on the full labeled set.

`--model mockllm/model` satisfies Inspect's model requirement without any API call — the solver does no
generation, it just surfaces the engine's precomputed predictions for scoring. Same file + same `seed`
⇒ byte-identical split, recorded in the `.eval` log under `./logs/`.

## Files

- `eval/dataset.jsonl` — generated by `npm run eval:build` (engine predictions over the synthetic fixtures).
- `eval/discrepancy_eval.py` — the Inspect task: a pass-through solver + a set-match scorer with custom
  per-class precision/recall metrics (a custom `@metric`, since `grouped()` can't see cross-class
  false positives).

> Note on N: the synthetic fixture set is intentionally small, so the per-class numbers carry real
> standard error — surfaced by `stderr()`, not hidden. The honest headline rate is the *separate*,
> pending real-capture number described above.
